# Frequent Value Imputation

-> This project demonstrates how to handle missing values using **Frequent Value Imputation**, which replaces missing data with the most commonly occurring (mode) value in a feature.  
-> We explore this concept using both **manual implementation with Pandas** and **automated implementation using Scikit-learn’s `SimpleImputer`**.

## Key Topics Covered:-
-> Understanding the concept of **Frequent Value (Mode) Imputation**
-> Implementation using **Pandas** and **Scikit-learn**
-> **Data Visualization** with Pandas to compare feature distributions before and after imputation
-> Handling **categorical and numerical** data effectively
 
## Tools & Libraries:-
-> Python  
-> Pandas  
-> NumPy  
-> Scikit-learn  
-> Matplotlib / Seaborn (for comparison plots)
 
### Goal:-
To visualize how imputing with the most frequent value affects data distribution and variance.
